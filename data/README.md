# 数据

人工整理的数据，存成 CSV：UTF-8 编码，逗号分隔，第一行是列名。提交前按各表写的顺序排好：几个人同时补充时改的是不同的行，不容易冲突。

- 用文本编辑器改，或者在 Excel 里另存为「CSV UTF-8」。Excel 默认存的 CSV 是 GBK 编码，提交上来是乱码。
- 某一格里有英文逗号或双引号的，整格用双引号括起来，里面的双引号写两遍。备注里用中文逗号就不用括。
- 只看公开的页面，手动打开确认，不写脚本批量抓。只放网址、标题和标注，不放通知的正文、快照和附件。

## 来源清单 `sources.csv`

第一批要接入的通知列表页，一行一个列表页。一个学院有几个列表页（学院的、研究生院的），就写几行。

| 列 | 内容 |
| --- | --- |
| `school` | 学校的全称，比如「电子科技大学」 |
| `college` | 学院的全称，以官网为准；研究生院就写「研究生院」 |
| `url` | 通知列表页的网址，打开确认过 |
| `months` | 往年发保研通知的大概月份，用空格隔开，比如 `5 6 9` |
| `note` | 打开时遇到的情况，比如「要执行脚本才显示内容」「只能用 HTTP」；没有就空着 |

按 `school`、`college`、`url` 排序。

## 初筛标注集 `screening.csv`

初筛实验用的通知标题和标注（[总体设计 §8.5](../docs/design.md#85-实验)），一行一条通知，明显无关的通知也要收。

| 列 | 内容 |
| --- | --- |
| `source_url` | 通知所在列表页的网址 |
| `section` | 列表页的栏目名，比如「通知公告」 |
| `url` | 通知的网址 |
| `title` | 列表上显示的标题，原样复制 |
| `relevant` | 是保研招生相关的通知填 `1`，不是填 `0`；范围见[总体设计 §8.1](../docs/design.md#81-初筛) |
| `note` | 拿不准的写明原因；没有就空着 |

按 `source_url`、`url` 排序，同一条通知只写一行。
